# Claude Code - Global Instructions

## Python

### Code Style and Standards
- Follow PEP 8 for code style
- Use type hints for all function signatures
- Maximum line length is 79 characters

### Imports
- Place all imports at the top of the file unless technically required otherwise
- Group imports in order: standard library, third-party, local
- Sort alphabetically within each group

### Error Handling
- Use specific exception types, not bare except
- Log errors appropriately
- Provide user-friendly error messages
- Use context managers for resource management

### Documentation
- Use docstrings for all public functions and classes
- Follow Google or NumPy docstring style consistently
- Include type hints in function signatures
- Document complex algorithms and business logic

## Git

- Write concise commit messages: a short imperative subject line, no body unless truly necessary
- Do not add Claude attribution or co-author trailers to commits
